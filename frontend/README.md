# RefMind 科研工作台前端

Vue 3 / TypeScript / Vite / Router / Pinia / Element Plus，原文使用 PDF.js，回答使用经过清理的 Markdown 与 KaTeX。

## 本地使用

```powershell
cd frontend
npm ci
npm run build
```

随后启动 RefMind FastAPI 服务。后端会在启动时挂载 `frontend/dist`；界面和 API 使用同一来源，路由采用 hash 模式。若服务在首次构建前已经启动，构建后需重启服务。

开发时可运行 `npm run dev`，默认将 `/api` 代理到 `http://127.0.0.1:8000`。不要把前端开发服务直接用作对外部署。

首次账号由项目的离线管理命令创建，前端没有默认账号或密码。所有需要授权的请求使用 HttpOnly 会话 Cookie，写操作附带 `/api/auth/me` 返回的 CSRF 值。

## 页面与资料边界

- 研读空间：本地文献、所选会话资料、混合研读；默认本地模式。原文与证据并排，窄屏切换显示。会话全文与摘要必须明确选择。
- 文献发现：显式提交后检索；逐源显示已有结果；筛选恢复与分页保持服务端检索条件。仅原站入口不等于可获取全文。
- 文献库：私有/共享库、文献筛选、PDF 上传、原文预览及所有者成员管理。
- 任务中心：后台进度、失败重试、取消请求、身份核验和部分页面的明确确认。
- 管理设置：实际账号创建/列表及不含密钥的运行配置摘要。这里不伪造供应商配置保存能力。

会话选择保存在当前用户的浏览器标签页会话中，仅记录资源/题录标识和题名；退出登录会清除。服务端继续逐次验证权限，浏览器状态不授予资料访问权。回答中的原文链接只打开当前答案证据快照允许的文献。

## 验证边界

`npm run build` 同时执行 TypeScript 检查与正式构建。界面未包含固定演示数据。开发期间的浏览器验证使用独立数据库、临时账号和明确标注的 QA fixtures，未请求真实学术索引或模型服务；不能据此宣称真实模型质量、下载成功率或多人负载已通过。

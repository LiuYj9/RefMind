# RefMind 前端离线界面验证记录

日期：2026-11-05（Asia/Shanghai）。前端 `vue-tsc --noEmit` 与 Vite 正式构建通过。

验证使用独立数据库和数据目录、临时账号、明确标注的合成 QA 文献与 PDF。测试服务仅监听 `127.0.0.1:8765`，任务执行器关闭，进程阻止非回环网络连接。没有调用真实模型、学术索引或公开全文站点，也没有使用真实论文或 holdout。

## 已通过的界面与真实本地 API 验证

- 错误密码显示真实 401 提示；临时账号通过 Enter 登录，登录后取得同源 Cookie/CSRF。
- Enter 创建隔离共享文献库；成员列表与添加只读成员调用实际 GET/POST 接口。
- 研读会话重命名调用实际 PATCH，侧栏与标题同步更新。
- 论文引用从其他页跳回第 2 页；证据区域高亮；文本层按 PDF 字号和缩放定位；KaTeX 公式显示。
- 桌面阅读器宽度与内容宽度均为 771 CSS px，没有水平溢出；独立滚动保留问答/原文。
- 无摘要题录仍可见；仅原站入口的结果不能提交获取全文，摘要选择与全文选择明确区分。
- 运行中检索任务已有论文可见，逐源显示“已返回/检索中”；query 恢复正常。provider/filters/limit 按最新 API 契约恢复，并通过类型与构建检查。
- 部分解析资料显示 2/3 页范围，经明确确认后，实际接口将任务标为“仅研读已解析页面”。
- 默认本地模式；没有外部选择时混合模式不能提交；显式摘要标签刷新可恢复；用户切回本地模式后刷新仍保持本地。
- 窄屏实际宽度约 390 CSS px，无整体横向溢出；图标导航保留可访问名称，历史会话、退出与问答/证据切换可操作。

## 发现并修复

- PDF.js 完整 viewer CSS 的全局 `.sidebar` 与工作台冲突，已改成仅作用于 PDF 页的文本层样式。
- 新版文本层需要正确的总缩放变量；原文渲染增加序号保护，避免异步翻页/缩放互相覆盖。
- 宽屏 padding 与初次滚动条导致轻微水平溢出，已按实际容器计算适配宽度并预留滚动条位置。
- 移动端保留图标标签、历史会话选择、退出入口和新建研读入口。
- 会话摘要与全文勾选状态按当前用户的标签页会话保存，包括明确的空选择；退出登录清理。
- 回答先清理模型 HTML 的媒体、样式与可执行内容，再插入受控 KaTeX，避免原始回答触发外部媒体加载。

## 验证范围

这些结果证明本地界面和所列 API 交互可用，不代表真实模型回答质量、真实公开全文获取成功率、10 人负载或所有解析文档的视觉定位已验收。

界面不包含固定 demo 数据。QA fixtures、临时凭据和截图保存在当前允许的工作目录中，没有复制到前端源码或正式数据库。

## 2026-11-06：文献库状态概览与详情同步

本次新增四类状态概览，使用隔离SQLite及合成文献，在实际浏览器1280×720视口验证；测试服务仅监听本机8767端口，阻止外部网络，无模型调用。预览进程已停止。

| 操作 | 观察结果 |
|---|---|
| 打开文献库 | 5篇总数；可研读2、处理中1、需要关注2 |
| 点击需要关注 | 仅保留2篇异常文献，右侧详情同步为可见文献 |
| 点击处理中 | 仅显示1篇解析中文献；维护操作禁用 |
| 点击可研读 | 仅显示2篇就绪文献 |
| 搜索不存在的题名 | 列表为空，详情清空，不显示此前文献 |
| 点击全部 | 清空搜索并恢复5篇文献 |

发现并修复筛选后详情仍停留在隐藏文献的问题。筛选结果变化时，保留仍可见的选中项，否则切换到首项或清空。此后重新完成类型检查和Vite构建；本轮前端14项既有测试通过。构建仍有主包体积告警，后续可独立评估拆分，未将其描述为性能验收通过。
